In the field & lab

From reef to
spreadsheet

Originally developed for coral recruitment studies in Palau, PolypPal was designed around the realities of fieldwork — underwater collection, lab photography with a ruler, and rapid measurement sessions with large sample sets.

The tool has since been validated against ImageJ on 23 recruits across 10 settlement plugs, achieving Pearson r > 0.994 at both timepoints.

Core capabilities

Built for precision,
designed for speed

Everything needed for two-timepoint size tracking, from a single unified interface.

Point-and-click Measurement

Click two points for each diameter — no image processing expertise required. Measurements appear in real-time as you work.

Automatic Image Registration

Detects and aligns objects across timepoints automatically. Manual rotation (q/e keys) fine-tunes alignment — coordinates transform accordingly.

Direct Excel Export

All diameters, calculated areas, status flags, and timestamps export directly to .xlsx. Annotated PNG images saved alongside.

Resume & Progress Tracking

JSON-based state means you can close the window and pick up exactly where you left off. Progress shown in metadata-driven mode.

Validated Accuracy

Compared against ImageJ on 23 recruits across 10 plugs. Pearson r > 0.994 at T1 and T2. Mean absolute error < 0.007 cm.

Fully Configurable

YAML config file controls image paths, output locations, and button labels — adapt status buttons for any application without editing code.

Quick start

Up and running
in minutes

  1. Clone & install dependencies

    Requires Python 3.8+. Works on Windows, macOS, and Linux.

  2. Organize your images

    Two directories — one per timepoint. Matching filenames across folders (e.g. sample_001.jpg in both).

  3. Configure via YAML

    Set input/output paths, optional metadata file, and customize button labels in config.yaml.

  4. Run and measure

    Launch with python polyp_pal.py config.yaml. Point-and-click your diameters. Close when done to export.

Installation
# Clone repository
git clone https://github.com/NicolasCroft/PolypPal.git
cd PolypPal

# Install dependencies
pip install -r requirements.txt
config.yaml
# Image directories
dir1: "/path/to/timepoint1"
dir2: "/path/to/timepoint2"

# Output files
output_excel: "/path/to/output.xlsx"
annotated_dir: "/path/to/annotated"

# Optional metadata
metadata_excel: null

# Customize status buttons
button_labels:
  status_1: "Dead"
  status_2: "Chimera"
Run
python polyp_pal.py config.yaml

Cite PolypPal

Using PolypPal
in your research?

PolypPal was validated against ImageJ measurements on settlement plug images and used in a coral feeding study examining the effects of heterotrophic diet on Acropora tenuis and A. digitifera recruits. Please cite accordingly if used in your work.

PolypPal: Interactive two-timepoint measurement tool for biological image analysis. GitHub. https://github.com/NicolasCroft/PolypPal

Associated manuscript: Alessi et al. (under review). Effect of heterotrophic feeding on growth and bleaching response of Acropora tenuis and A. digitifera juveniles. Coral Reefs.
